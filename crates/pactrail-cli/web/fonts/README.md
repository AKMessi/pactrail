# Bundled fonts and icons

IBM Plex Sans (400, 500, 600) and IBM Plex Mono (400, 500) use Latin WOFF2 subsets from `@fontsource` 5.2.6. They are distributed under SIL OFL 1.1; see the IBM Plex section of [THIRD_PARTY_NOTICES](../../../../THIRD_PARTY_NOTICES).

Lucide SVG symbols are bundled locally under ISC; see the Lucide section of [THIRD_PARTY_NOTICES](../../../../THIRD_PARTY_NOTICES). There are no runtime CDN requests.
