## Scope and follow-up

Source snapshots and SHA-256 hashes:
`benchmark-results/agent-quality-program-20261005/harness-sources/`.
The table records selected source paths, not proof that every subsystem works.
Benchmark numbers from README files are not imported as Pactrail results.

The priority experiments are edit reliability, bounded information delegation,
context retrieval and completion classification. ACP/DAP and a shared runtime
remain dependent on those measurements and the durable-runtime design. Codex
documented skill/sandbox behavior was also checked against [official skills
documentation](https://developers.openai.com/codex/skills) and [official security
documentation](https://developers.openai.com/codex/security). These pages can
change independently of the pinned source snapshots.

Further review must trace the execution paths and tests of each mechanism being
implemented. A README or selected handler alone is insufficient evidence of
system-wide containment, reliability, or comparative coding quality.
